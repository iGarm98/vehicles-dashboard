# vehicles-dashboard# Vehicles Dashboard

## Descripción del proyecto

Este proyecto consiste en una aplicación web interactiva desarrollada con Streamlit para analizar un conjunto de datos de anuncios de venta de vehículos en Estados Unidos.

La aplicación permite visualizar información del dataset mediante gráficos interactivos para facilitar el análisis exploratorio de datos.

## Funcionalidades

* Visualización de un histograma del kilometraje de los vehículos.
* Visualización de un gráfico de dispersión entre precio y kilometraje.
* Interfaz interactiva con botones para generar los gráficos.

## Tecnologías utilizadas

* Python
* Pandas
* Plotly Express
* Streamlit

## Cómo ejecutar el proyecto localmente

1. Clonar el repositorio:
   git clone https://github.com/iGarm98/vehicles-dashboard.git

2. Instalar dependencias:
   pip install -r requirements.txt

3. Ejecutar la aplicación:
   streamlit run app.py
